# Практикум «ТехноМаркет»

Учебный проект по анализу синтетических данных интернет-магазина на Python. В наборе рассматриваются клиенты, заказы, товары и возвраты; результаты анализа сохранены в Excel-отчёте и графиках.

## Что входит

- Очистка данных и обработка пропусков и дубликатов.
- Расчёт выручки и прибыли, сегментация и агрегирование.
- Анализ возвратов и помесячной динамики.
- Графики и форматированный Excel-отчёт.

## Запуск

Требуется Python 3. Установите библиотеки и запустите скрипт из корня репозитория:

```bash
python -m pip install pandas numpy matplotlib openpyxl
python starter_template.py
```

Скрипт читает исходные файлы из `data/`. В репозитории также сохранены готовые отчёты и визуализации.

## Структура

| Путь | Содержимое |
|---|---|
| `starter_template.py` | Скрипт анализа |
| `data/customers.csv` | Данные клиентов |
| `data/orders.csv` | Заказы; разделитель `;`, десятичная запятая |
| `data/returns.csv` | Возвраты |
| `data/products.xlsx` | Каталог товаров и поставщиков |
| `otchet_formatted.xlsx` | Форматированный отчёт |
| `otchet.xlsx` | Исходный файл отчёта |
| `*.png` | Графики анализа |

Данные в проекте синтетические и предназначены для обучения.
