# Praktikum-Tehnomarket

## Практикум «ТехноМаркет» — анализ данных для образовательных целей

### Описание проекта
Этот проект содержит синтетические данные для практикума аналитиков данных по торговой платформе «ТехноМаркет». Данные содержат информацию о клиентах, заказах, возвратах и каталоге товаров.

### Структура данных
- **customers.csv** — данные клиентов (610 записей)
- **orders.csv** — данные заказов (4230 записей), разделитель `;`, десятичная запятая
- **returns.csv** — данные о возвратах (320 записей)
- **products.xlsx** — каталог товаров (124 товара) с листами «Товары» и «Поставщики»

### Выполненные задания
1. **Загрузка и первичный осмотр** — загрузка данных с правильными кодировками и разделителями
2. **Очистка данных** — обработка пропусков, дубликатов, нормализация городов, извлечение брендов
3. **Признаки и фильтрация** — расчет выручки, прибыли, год/месяц, топ-заказов
4. **Группировки и агрегация** — выручка по категориям, каналам, средний чек
5. **Объединение таблиц** — широкая таблица клиенты-заказы, топ-5 городов, сегменты
6. **Сводные таблицы и возвраты** — pivot-table, доля возвратов, топ-5 возвращаемых товаров
7. **Временные ряды** — выручка по месяцам, лучший/худший месяц, скользящее среднее
8. **Визуализация** — 4 графика в PNG (бары, линия, круговая диаграмма, горизонтальные бары)
9. **Выгрузка отчёта** — otchet_formatted.xlsx с несколькими листами и форматированием
10. **Повышенная сложность** — ABC-анализ, RFM, когорты (по желанию)

### Результаты
- Выручка по категориям и каналам продаж
- Топ-5 городов по выручке
- Доля возвратов: 8.86%
- Лучший месяц: Октябрь 2024 (25.2 млн руб.)
- Худший месяц: Февраль 2023 (1.5 млн руб.)
